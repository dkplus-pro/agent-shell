## 状态约定

- **提议**：待讨论，不得据此实现；
- **已接受**：实现必须遵守；
- **已废弃**：被新 ADR 取代，保留历史；
- **已修订**：内容更新，需在文末记录修订。

## 模板

```markdown
# ADR-XXXX · 标题

> 状态：提议 / 已接受 / 已废弃 / 已修订  
> 日期：YYYY-MM-DD  
> 关联：...

## 背景

为什么需要做这个决策；约束与目标。

## 决策

做什么，不做什么；关键参数。

## 后果

正面、负面、风险。

## 备选方案

评估过但没有选择的方案，以及原因。

## 复审条件

什么情况下需要重新审视。
```
